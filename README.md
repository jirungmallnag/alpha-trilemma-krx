# Alpha Trilemma 검증 — KRX 데이터로 본 한국 ETF와 모멘텀

Korea Buyside Forum 2026 키노트에서 최동근 팀장(NH-Amundi자산운용)이 제시한
액티브ETF의 **Alpha Trilemma** — Cult · Purified · Hedgeable Alpha — 를
KRX Open API 데이터로 검증하는 개인 연구 프로젝트입니다.

## 질문

| 장 | 질문 | 상태 |
|---|---|---|
| 1 · Cult Alpha | 액티브·테마 ETF는 모멘텀에 얼마나 노출돼 있는가 | 데이터 수집 중 |
| 2 · Purified Alpha | 모멘텀 크래시를 미리 피할 수 있는가 | 사전등록 초안 |
| 3 · Hedgeable Alpha | LP가 헤지하기 어려운 ETF일수록 NAV 대비 괴리가 큰가 | 데이터 수집 중 |

## 원칙

- 가설과 판정 기준은 **결과를 보기 전에** `prereg/`에 커밋합니다. 커밋 시각이 그 증거입니다.
- 커밋 이후 바꾼 내용은 각 사전등록 파일의 변경 기록에 남깁니다.
- 통과하지 못한 가설도 그대로 보고합니다.

## 데이터

KRX Open API(비상업적 이용)에서 받았습니다. 이용약관상 원데이터는 제3자에게 제공할 수 없어서
이 저장소에는 **코드와 결과 요약만** 있습니다. 같은 결과를 보려면 직접 인증키를 받아 수집 스크립트를 실행하면 됩니다.

## 선행 작업

2015~2025년 KOSPI 상위 350종목 12-1 모멘텀 백테스트에서 평균 Rank IC는 −0.0064(t = −0.47)로,
교과서 강도의 모멘텀은 확인되지 않았습니다. 2장은 이 결과에서 출발합니다.
